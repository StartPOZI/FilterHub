## Обзор

SpiPrivacy Blocklists - это коллекция из 41 списка блокировщиков для браузеров и adblocker-расширений. Проект автоматически скачивает и структурирует списки из различных источников.

## Использование списков

### В uBlock Origin

1. Откройте настройки uBlock Origin (значок расширения → Настройки)
2. Перейдите в раздел "Фильтры" → "Списки фильтров"
3. В разделе "Пользовательские" нажмите "Очистить"
4. Вставьте URL из README.md нужного списка
5. Нажмите "Применить изменения"

Пример URL:
```
https://easylist.to/easylist/easylist.txt
```

### В AdGuard

1. Откройте AdGuard → Настройки → Блокировка рекламы
2. Нажмите "Добавить список"
3. Вставьте URL и нажмите "ОК"

### В Brave Browser

1. brave://settings/adblocking
2. Разверните "Пользовательские списки"
3. Добавьте URL

## FAQ

### Сколько места занимают списки?

Вместе все списки занимают примерно **85 MB**. Самый большой - HaGezi TIF (43 MB).

### Можно ли использовать все списки одновременно?

Не рекомендуется. Используйте:
1. Один основной рекламный список (EasyList или Adguard Base)
2. Один приватный (EasyPrivacy)
3. Дополнительные по необходимости

### Что означает "не удалось скачать"?

Это означает, что сервер источника не ответил в течение 60 секунд. Попробуйте позже или используйте альтернативный источник.

### Как обновить списки?

Запустите скрипт:
```bash
cd "/home/tim/Списки SpiPrivacy"
bash download_lists.sh
```

### Какой список самый мощный?

HaGezi TIF (#39) с 2,175,386 правилами. Он же и самый большой по размеру (43 MB).
